# MediVoice Edge

This repository hosts the new, unpublished edge-native voice-registration pipeline for the ASUS UGen300 (Hailo-10H) built for the ASUS UGen AI League Innovation Hackathon (Workplace AI theme, Battlefield Lightning, Global Online Track, solo entry by Muhammad Khizar). Stage I is laptop simulation; the public cloud prototype used only as feasibility evidence lives at https://github.com/khizzcr7/ai-patient-registration-system.
